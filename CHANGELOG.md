# История изменений

## 0.1.0 - 14.10.2026

Первый релиз.

- три мира на TypeScript: `cef/` (Vue 3 + Vite + Pinia), `client/`, `server/`
- `shared/events.ts` - типы всех событий в одном файле, ошибки ловит компилятор
- мок-панель сервера в браузере - интерфейс разрабатываешь без игры
- HUD-спидометр, чат на T, плашка игрока, телефон из rp-ui-kit
- `/veh` выдаёт машину, спидометр сам берёт скорость из игры
- `npm run build` - готовый `server-files/`, `build:dev` - hot-reload в игре
- минимальные типы RAGE MP API в `types/ragemp.d.ts`
- русские README и GUIDE, короткий английский README
