# Гайд: от нуля до первой поездки

Для тех, кто RAGE MP сервер поднимает впервые. Займёт минут 15.

## Что надо

- Node.js 18+ - [nodejs.org](https://nodejs.org), ставь LTS. Проверка: `node -v`
- Сервер RAGE MP - скачивается с [rage.mp](https://rage.mp) (раздел Downloads, Server package)
- Желательно VS Code - он подчеркнёт ошибки в типах

Сервер распакуй в отдельную папку. Там будут `ragemp-server.exe`, `client_packages/`, `packages/`.

## 1. Скачать и поставить

```bash
git clone https://github.com/hilsetapp/rp-vue-starter.git
cd rp-vue-starter
npm i
```

## 2. Погонять интерфейс без игры

```bash
npm run dev
```

Открой http://localhost:5173. Видишь спидометр, чат и пунктирную панель «МОК СЕРВЕРА»?
Значит всё встало.

Что потыкать:
- ползунки скорости и оборотов - HUD меняется
- Enter - чат открылся, отправка эхом вернётся
- F2 - прячет HUD
- кнопка «телефон» - телефон из rp-ui-kit

Правки в `cef/src/` применяются сами, страницу даже перегружать не надо.

## 3. Собрать и влить в сервер

```bash
npm run build
```

Получится папка `server-files/`:

```
server-files/
  client_packages/
    index.js      мост + цикл спидометра
    cef/          собранный интерфейс
  packages/
    rp/index.js   серверная логика
```

Скопируй всё из `server-files/` поверх папки сервера из первого шага.
Папки совпадут по именам, RAGE сам подхватит пакет `rp` при запуске.

## 4. Запустить и заехать

1. `ragemp-server.exe`
2. В клиенте RAGE: Direct connect -> `127.0.0.1:30105`
3. При входе в чат прилетит приветствие, справа сверху твой ник и деньги
4. В игровом чате напиши `/veh` - рядом появится Sultan и ты в него сядешь
5. Газуй. Справа снизу спидометр будет показывать настоящую скорость,
   обороты дышат, название района меняется. T - чат, F2 - спрятать HUD

Всё. Контур «интерфейс <-> клиент <-> сервер» работает, можно строить своё.

## Горячая перезагрузка в игре

Чтобы не собирать после каждой правки:

```bash
npm run dev        # терминал 1
npm run build:dev  # соберёт server-files, но интерфейс будет тянуться с vite
```

Копируешь server-files как обычно, рестарт сервера - и правки в Vue-файлах
видны в игре мгновенно. На прод обратно `npm run build`.

## Как добавить своё событие

Пример: сервер говорит интерфейсу, сколько игроков онлайн.

1. `shared/events.ts`, в `ClientToCef`:

```ts
'players:online': { count: number };
```

2. на сервере:

```ts
emitAll('players:online', { count: 24 });
```

3. в интерфейсе:

```ts
on('players:online', (d) => { store.online = d.count; });
```

Опечатаешься в имени - подчеркнёт ещё до запуска.

## Если что-то не так

| Симптом | Что сделать |
|---|---|
| Пустой экран в игре | открой ту же страницу через `npm run dev` в браузере и смотри консоль (F12) |
| `npm i` падает | Node обнови до LTS, удали `node_modules` и package-lock, поставь снова |
| Сервер не видит пакет | проверь путь: ровно `packages/rp/index.js`, без лишней вложенности |
| HUD не двигается | нужно в машину: `/veh` и газ |
| Чат не открывается по T | кликни в игру мышью, фокус мог уйти |
| Порт 5173 занят | vite сам предложит другой, его же пропиши в `CEF_DEV_URL` при сборке build:dev |

Не лечится - пиши в Issues, разберём.
